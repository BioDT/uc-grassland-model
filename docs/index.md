# An individual-based and process-oriented grassland model combining biodiversity and biogeochemical cycles

GRASSMIND is an individual- and process-based grassland model designed for simulating the structure and dynamics of (managed) species-rich herbaceous communities. It combines biogeochemical matter fluxes (carbon, nitrogen and water) with plant diversity, driven by environmental conditions (weather and soil) and by explicit management actions (e.g. cutting, fertilization).

On the following pages you can find a detailed model documentation (following the ODD protocol), tutorials for various application examples and links to the source code and code releases.
