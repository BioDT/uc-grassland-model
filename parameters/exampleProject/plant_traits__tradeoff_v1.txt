# =============================================================================
#
#  GRASSMIND exemplary trait-based parametrization
#  Groups of plants (PFT): 1-grasses, 2-forbs, 3-legumes
#
#  Intended use: stylised temperate, perennial grassland PFTs.
#  These are internally contrasted starting values, NOT species-specific
#  calibrations. Validate units, biomass geometry, and emergent monoculture
#  behaviour against the implementation and target site before inference.
#
#  Strategy contrasts represented here:
#  1. Grasses: dense, relatively shallow fine-root foraging; conservative,
#     long-lived tissues; efficient use of N and water; strong occupancy.
#  2. Forbs: lower-density but taller/broader shoots; relatively deep roots;
#     acquisitive leaves and rapid growth when resources are available, with
#     higher turnover and poorer drought tolerance.
#  3. Legumes: N2 fixation coupled to a carbon cost; high leaf N and potential
#     photosynthesis; intermediate-to-deep roots; relatively high water demand.
#

# =============================================================================
